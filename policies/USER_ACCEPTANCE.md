# User Acceptance and Delivery Gateway

Only the DELIVERY / CONTROL LEAD may publish authoritative overall project status to the user. Individual Workers report Task-local state only.

Authoritative delivery must reference `CANONICAL_INTEGRATION_SHA`, `PRODUCTION_SHA`, and `LATEST_RELEASE`, state what is complete/incomplete, identify blocked/waiting-for-user work, and distinguish verified facts from pending acceptance.

Competing Worker summaries are non-authoritative.
