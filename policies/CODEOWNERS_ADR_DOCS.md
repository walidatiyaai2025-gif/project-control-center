# CODEOWNERS, Architecture Decisions and Documentation Drift

Critical control-plane and governance paths should have CODEOWNERS coverage. Architecture decisions that materially alter system structure, data contracts, security, deployment, integration, or control-plane rules require an ADR.

Documentation is part of delivery. If implementation changes invalidate operational, architecture, API, migration, support, or user-facing documentation, the task cannot be DONE until drift is reconciled or explicitly tracked by a linked Task ID.
