# PCC v1.4.0 — Execution Output Discipline Add-on

PCC v1.3.0 was already promoted and externally reported, so its source identity is not reused. This material governance add-on advances PCC to v1.4.0.

Added without rebuilding prior governance:
- mandatory `EXECUTION_OUTPUT_DISCIPLINE_POLICY`;
- silent execution default for operational roles;
- six structured handoff schemas;
- exact-head and artifact-provenance gates;
- Visual QA provenance requirements;
- contradiction and stale-evidence gates;
- machine-checkable output validator;
- regression tests for narration, speculation, provenance, contradictions, blockers, missing HEAD and unsupported DONE.

AIMWWeb remains a read-only pilot target; this add-on does not modify its repository.
